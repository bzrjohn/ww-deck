Technical SEO

Speed & Core Web Vitals.

Page speed is the foundation. Until mobile performance is fixed, every other SEO investment delivers diminished returns. This is the first priority.

Priority Technical Fixes

1. Image Optimisation

Convert images to WebP/AVIF, implement lazy loading, serve responsive sizes. Often the single biggest speed improvement.

2. JavaScript & CSS Audit

Identify and defer render-blocking resources. Remove unused scripts and stylesheets. Minimise third-party script impact.

3. Server & Hosting Review

Evaluate TTFB (Time to First Byte), implement CDN if not already, enable proper caching headers. Consider edge caching for static pages.

4. Schema & Structured Data

Implement Organisation, LocalBusiness, Person (Chris Bates), and Review schema. Enables rich snippets and knowledge panel improvements.

Core Web Vitals Targets

Google's three key performance metrics that directly impact rankings:

LCP (Largest Contentful Paint) Target: <2.5s

How quickly the main content loads. Critical for first impressions.

INP (Interaction to Next Paint) Target: <200ms

How responsive the page feels when users interact. Affects form submissions and CTAs.

CLS (Cumulative Layout Shift) Target: <0.1

Visual stability — elements shouldn't shift around as the page loads.

Speed is a ranking factor, but it's also a conversion factor. Every 1-second delay in mobile load time reduces conversions by up to 20%. For a high-value service like mortgage broking, that translates directly to lost enquiries and lost revenue.
